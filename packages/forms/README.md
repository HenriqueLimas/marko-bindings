# Form bindings

Bindings for form state, validation, field composition, and submission workflows.

Packages in this group should retain native form semantics, support server rendering, and model fields and validation through composable Marko tags rather than callback-only APIs.

## Packages

- [`@marko-bindings/tanstack-form`](tanstack-form) — lifecycle-owned TanStack
  forms and fields with reactive, resumable Marko facades.
